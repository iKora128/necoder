### 1.2 アイデンティティ色

- **プロジェクト色パレット（自動巡回）**: indigo `#7c8cf8` → teal `#34d3b6` → amber `#f0a24b` → rose `#ef7d9b` → green `#85c46c`
- **アイデンティティ・パレット（ピッカーの正典）** = `theme_core::IDENTITY_PALETTE_HEXES`: 上の巡回5色 + 予約色（Claude バレット `#d97757`・スレッド色・選択面 `#7d9bd8`）と衝突しない厳選色（cyan / chartreuse / violet / magenta / graphite）。**巡回もピッカーもこの1本が出所**
- 優先順: `.necoder/settings.json` の `color` > **ローカル DB `project_colors`**（手動選択と初回の自動割当を焼いたもの・キーは local/ホスト鍵 + root パス）> 未使用のパレット色。**色はプロジェクトに付き、レールの並び順・窓・再起動で変わらない**（2026-09-07。自動割当だけが同窓の衝突を避け、決まった色は衝突しても尊重）。リモートも同じ 1 プロジェクト 1 色（旧: ホスト単位）。手動選択の導線 = レール右クリック / **⌘K⌘C** / コマンドパレット「表示: プロジェクトの色を変更」→ 厳選スウォッチ or **任意 hex 入力**（ローカルは `.necoder/settings.json` と DB の両方へ・リモートは DB のみ）
- 任意 hex はエスケープハッチ: §1.3 の流れ先（許可リスト）は変えない。**細い accent としての可読性はユーザー責任**（Peacock と違いコントラスト自動計算はしない）
- **スレッド色パレット（自動巡回）**: `#61afef` → `#e5c07b` → `#c678dd`（プロジェクト色と独立）
- accent-dim = プロジェクト色 16% 透過（パレット選択面・タイル選択輪郭のみ）

- **スマホ PWA（§15）の色**（2026-10-01）: 考え方はデスクトップの**窓縁の枠**と同じ — 画面の縁の色で「今どれを見ているか」を示す（識別）。スマホは 1 画面 = 1 会話で、窓縁 2px やタブ上線が小さすぎて効かないので、会話画面の上端バーを**そのスレッドのタブ**としてスレッド色 22% の面（ステータスバーの裏まで・theme-color も同色）+ 下線 2px にする。プロジェクト色は一覧の塊の左端の縦線 3px と、プロジェクト名の前の縦棒 3px（ピル左縁と同じ流儀）。状態に色相を使わない・グラデを使わないのはスマホでも同じ

### 1.4 寸法・密度・タイポグラフィ

- 密度 compact（既定）: 行高 23 / padding 6 / UI 12.5px / code 13px lh1.55。cozy: 27 / 9 / 13 / 13.5 lh1.7
  - **実装済みの範囲**（O27・2026-09-26）: 設定 › 外観 の「行の間隔」（`density`・`詰める` / `ゆったり`）で、**リストの行の高さ**だけを切り替える: エクスプローラの行（23 → 27）・ピッカーの行（上下 4 → 6）・検索の結果の行（20 → 24）・Fleet の Task / 統合先 / 外部の worktree の行（+4）。使う側は `ui::row_height(cx, compact)` / `ui::row_padding(cx, compact)` で引く（global `ui::RowDensity`・書体と同じく設定が変わると置き直して窓を描き直す）。文字の大きさ・コードの行の高さは変えない（UI ズームは未）。Git パネルの行は未（O18 の作業中）
- 固定寸法: レール 46・左ドック 218（カラム/アイコン時 462）・右ドック 340・titlebar 38・タブ列 34・パンくず 26・statusbar 26・ターミナル既定 240（60〜900 で可変）・行番号ガター 46（右寄せ）+ git バー 3px
- 角丸: 窓 10・ピル/ボタン 5–6・カード 8–9・パレット 12
- フォント: UI = **IBM Plex Sans JP**、コード = **Guguru Sans Code**（Google Sans Code + IBM Plex Sans JP の等幅）。どちらも同梱（SIL OFL・バイナリに埋め込み）。settings.json の `ui_font_family` / `code_font_family` で差し替えられる（O27・空 = 同梱・入っていない書体は OS の代わりの書体で描く）。**設定 › 外観 の「UI の書体」「コードの書体」「ターミナルの書体」**の「選ぶ…」で、入っている書体（OS の一覧・名前順・`.` で始まる内部名は除く）を ⌘P と同じピッカーで絞り込んで選べる（先頭 = 既定に戻す・いまの書体は行頭●）。「既定に戻す」は設定がある時だけ。使う側は名前を直書きせず `ui::ui_font(cx)` / `ui::code_font(cx)` で引く（設定が変わると窓を描き直す）。ターミナルの本文は `terminal_font_family`、空ならコードの書体。太字は 600–700 のみ

## 2. レール（プロジェクトの方向感覚・常設）

- 項目 = 30×30 角丸8。中身は優先順: `.necoder/settings.json` の `icon`（絵文字 or 画像パス）> 規約パス `.necoder/icon.png`（jpg/jpeg/webp も可・置くだけで効く）> プロジェクト名の頭文字（例: 印）。画像でも**色の枠は残す**（識別は色・画像は装飾＝§1.3）
- 状態: active = プロジェクト色の枠 + 2px リング / hover = 枠のみ / 通常 = 色 14% の面 + 35% の枠 / **⌘O で選んでいる行の行き先** = active と同じ枠 + 24% の面 + レールの左端の縦棒（§7・開いている間だけ）
- 下部に**実行中スレッドのドット**（5px・スレッド色・実行中 pulse 1.6s）→ 他プロジェクトの動きが常に見える
- ＋ = **統一オープン**（`open_launcher`）: フォルダ / ファイル / リモート + **最近（local + remote 混在・opened_at 降順）** を 1 枚の広いファジー面に。最近行は ●識別色 ＋ 実行中ドット、リモートは `host:path` で識別。⏎ = 現レールに開く。⌘O は開いているプロジェクト間の切替（別物）。左クリック = 窓内切替（ARCHITECTURE §5）。ドラッグ並び替えは v1
- **右クリック = コンテキストメニュー**（M10-2）: 色スウォッチ + 「その他の色…」（フル hex ピッカー）／新しいウィンドウで開く／**パスをコピー・ブランチ名をコピー**（O21・ブランチが分かる時だけ・写したらトースト「コピーしました: …」）／**この Task から新しい Task…**（O21・A07・`↳`・統合先でない Task だけ: その Task へ移り、＋ Task を起点にその Task のブランチを入れて詳細を開いた状態で開く。作った Task は子になる）／**詳細…**（O21・A12: 中央のカード 420 幅に 種類と状態・ブランチ・起点（8 桁）・**親の Task / 子の Task**（A07・ある時だけ・閉じた親は「（閉じた Task）」）・場所（ホーム下は `~/`）・作った時・スレッド（数とエージェント）・最後の依頼（1 行目・160 字まで）・トークン。下にパス / ブランチ名のコピーと「閉じる」。読むだけ・外側を押しても閉じる）／レールから外す／(worktree タブのみ) worktree を削除・worktree ごとブランチを削除。破壊的操作は二段確認（もう一度クリックで実行）
- **アクティビティアイコン**（下部・explorer/search/git/todos/threads/agent/terminal/remote）: 表示中のビュー/ドックだけプロジェクト色・他は fg2（§1.3・VSCode の Activity Bar 準拠）。active 判定 = explorer:左ドックがツリー / search:検索パネル開 / git:git パネル開 / todos:板開 / **threads:左カラムが AI スレッド一覧**（`activity.svg`・全プロジェクトのスレッド状態＝ herd。Fleet 中は同じ枠が Fleet サイドバーで、エクスプローラへ切り替えた後の帰り道を兼ねる。Todo / git と排他・押し直すとエクスプローラ・Chat では不活性・2026-09-24）/ agent:右ドック表示 / terminal:下ドック表示 / **remote:SSH ホストピッカーを開くアクション（server アイコン・アクティブプロジェクトがリモートなら色付き・#2）**
- **リモート slot**（レールのプロジェクト）: SSH 接続先はモノグラム右下に **server バッジ**（プロジェクト色・ローカルと見分ける・#2）。窓縁 2px 枠（§1.3）と併用
- **レールを押すと ↑/↓ でプロジェクトを流せる**（2026-09-12・旧「レール = 最後に触った面」を置換）: レールのどこか（項目でも空き地でも）を押すと**レールにフォーカスが移り**、面が bg2 に上がる（bg1 は実機で差が小さかったため強めた）。フォーカスがある間だけ **素の ↑/↓ が前後のプロジェクト切替**（⌃⌘↑↓ と同じ循環・行き先名フラッシュあり）。切り替えてもフォーカスはレールに残る＝連打で流せる。**Escape** で作業面へ戻り、レール外をどこか押しても戻る。トラックパッドで「突いて ↑↓」の動線
  - 素の ↑/↓ は keymap ではなく `on_rail_key_down` で受ける。gpui はコンテキスト無しのバインドを**最深**として解決するので、keymap に足すとエディタのキャレット移動を全域で殺す。Workspace コンテキストへ足すと逆に Editor より浅くて負ける
  - **⌘{ ⌘} の付け替えは廃止**（旧仕様。押した履歴でキーの意味が変わる隠れモードだった）。⌘{ ⌘} は常にエディタタブ切替
  - レールにフォーカスがある間は **Editor コンテキストの束（⌘S・⌘Z・⌘C/⌘V 等）が効かない**。左ドックや git パネルにフォーカスがあるときと同じ挙動で、Escape かクリックで戻れば復帰する

## 3. titlebar / statusbar

- titlebar: 信号機 → **ピル**（枠1px・左縁3pxプロジェクト色。名前クリック=⌘O、`⎇ branch ▾` クリック=branch/worktree メニュー）→ spacer → **beacons**（アクティブ project のスレッド、色ドット+名、実行中 pulse）→ **ベル**（通知の履歴）→ SSH → ドック開閉アイコン×3

- **ファイル操作の取り消し（H30）**: エクスプローラにフォーカスがある時の **⌘Z** で、作成・名前の変更・移動・複製・Finder からのコピー・ゴミ箱を新しい順に 1 手ずつ戻す（keymap の `Explorer` コンテキスト＝エディタの ⌘Z とは別。履歴は project ごと・メモリのみ・50 手）。エクスプローラを押す（左・右クリック）とフォーカスが移り、Esc で作業面へ戻る。ゴミ箱は `/usr/bin/trash -v` が出す「ゴミ箱の中での場所」を覚えて戻す。戻せない時（場所が分からない・ゴミ箱に無い・戻し先に同名・未保存の変更がある）はトーストで理由を出す。作成の取り消しは空なら消し、中身があればゴミ箱へ（完全削除しない）

    - **necoder の窓の中に付けない**（macOS）: WebKit は既定で Inspector を WebView の横に付け、その時 WKWebView を**窓全体の幅**に広げるので、レール・エクスプローラ・右のパネル・ステータスバーが全部隠れて何も押せなくなる（2026-09-27 本人報告「全画面になって何も戻れない」）。付いたら（Inspector の「ウインドウ下端にドッキング」「ウインドウの左 / 右にドッキング」を押しても）すぐ**別の窓**へ出し、WebView を元の場所へ戻す（`webview_view::inspector`）。1 度出すと WebKit がアプリの設定を覚え、次からは初めから別の窓で開く

  - オーバーレイ中に隠す・キーボードフォーカスの受け渡し・15 分の破棄は HTML プレビュー / PDF と同じ規律（§7・ARCHITECTURE §3）
  - **HTML ファイルを開く（内蔵の配信・2026-09-26）**: 開発サーバの無いただの HTML も Web タブで見て Design モードを使える。入口 = HTML プレビュー（⌘⇧V）中のパンくずの `Web タブで開く`（Lucide mouse-pointer-click + 文字・fg2・↻ と `ソース` の左。artifact の閉じ込めたプレビューと Chat には出さない）/ エクスプローラの `.html` の右クリック「Web タブで開く（Design モード）」（「開く」の下・手元のプロジェクトだけ）/ パレット「プレビュー: HTML を Web タブで開く（Design モードが使える）」（アクティブなタブの `.html`。違えばトースト）
    - 配信（`webview_view::static_server`・std だけ）: `127.0.0.1` のランダムなポートに bind。URL = `http://127.0.0.1:<port>/<token>/<相対パス>`（token = 開くたびに作る 128 bit）。配るのは**そのファイルのフォルダの中だけ**・読み取り専用（GET / HEAD・他は 405）。`..`・`%2e%2e`・外を指すシンボリックリンク・`.` で始まる名前（`.env`・`.git`）は 403、token 無し / 知らない token は 404、**Host が `127.0.0.1:<port>` 以外は 403**（DNS rebinding）。`Cache-Control: no-store`・`nosniff`・CORS のヘッダ無し・一覧は出さない（フォルダは `index.html`）。ページのルート相対（`/style.css`）は token 付きのページから来た時（Referer）だけ同じ token の下へ転送（ビルド済みの `dist/` がそのまま動く）

    - 再読込: 配っているフォルダの中のファイルが変わったら、既存のファイル監視（200ms 合流）から Web タブを読み込み直す。ページに live reload のスクリプトは差し込まない。プロジェクトの外の HTML は監視の外（↻ で読み込み直す）
    - 表示: URL 欄は token 付きの URL でなく `フォルダ名/相対パス`（例 `public/index.html`）、ツールチップ「内蔵の配信: <ディスクの上のパス>」。タブ名はタイトル（無ければ同じ短い表記）。Design の説明の「ページ」もファイルのパス（AI が直すのはそのファイル）
    - 対象外（トースト）: SSH のプロジェクト（「SSH のプロジェクトの HTML は、まだ Web タブで開けません（内蔵の配信は手元のファイルだけ）」）・Chat（エージェントの書いた HTML は artifact として閉じ込めたまま）

- **タブのドラッグで右に並べる**（O24・C03・2026-09-26）: タブをドラッグしている間だけ、本体の右 35% が落とし先になる（エディタのタブが上に来た時だけ地が bg2 85% + 左罫線 1px・色相は使わない）。落とすとそのタブのファイルを右の分割ペインに並べる（⌘\ と同じ副ビュー・開いていれば中身を差し替える・主ペインのタブと選択はそのまま）。エディタのタブでない物（画像・PDF・Web・端末・変更レビュー・diff）はトースト「ファイルのタブだけ右に並べられます」
- **衝突の帯**（O19・E05・2026-09-26）: アクティブなエディタのファイルに git の衝突の印（`<<<<<<<` 〜 `>>>>>>>`・diff3 の `|||||||` 付きも・7 つ並びだけ）があれば、外部変更の帯と同じ場所・同じ形（高さ 30・warn 12% の面・下罫線）で `⑂ 衝突 N か所（M 行目）` + `今の側（HEAD）` `入ってくる側（ブランチ名）` `両方` `次へ ↓` `並べて見る`（印の名前が無ければ括弧を出さない）。対象はキャレットのある衝突（無ければ後ろで最初・末尾を過ぎたら先頭）。解決は 1 回の編集（⌘Z 1 回で戻る）で、キャレットは解決した所へ。数え直すのはバッファの版が変わった時とタブを移った時だけ（描画のたびに読まない・4 MB を超えるファイルは見ない）。パレットに同じ操作（「マージ: 衝突を今の側で解決」等・「マージ: 次の衝突へ」）と「Git: マージ / リベースを中止」（進行中の方を `git rev-parse` で確かめ → OS のダイアログで確認 → `git merge --abort` / `git rebase --abort`・どちらも無ければトースト・リベースを先に見る＝ `rebase -r` がマージで止まった時もリベースとして中止）。
- **衝突を並べて見る**（O19・E05・2026-09-26）: 帯の `並べて見る`・パレット「マージ: 衝突を並べて見る」で、中央のカード（幅 86%・高さ 86%・bg2・角 10・影 28px・外側は 25% の暗幕で、押すと閉じる）。見出し `衝突 i / N（M 行目）`（13px・SEMIBOLD）。上半分はキャレットの衝突の **今の側（HEAD）/ 元（共通の祖先）/ 入ってくる側（ブランチ名）** の列（元は diff3 の印にある時だけ・無ければ 2 列で、下に fg2 10.5px「元の版は印に入っていません（git config merge.conflictStyle diff3 で入ります）」）。列は枠 1px・角 6、見出し（bg1・11px・fg1）とコードの書体 12px の中身（縦にスクロール・タブは空白 4 つ・空の側は fg2 の「（空）」・400 行を超えた分は「… 他 N 行」）。下半分は **結果の欄**（列と同じ枠と見出し。見出しは `結果（直してから ⌘⏎ で解決）` と、右寄せの fg2 11px の `今の側から` `元から`（元がある時だけ）`入ってくる側から` `両方から`＝押すと欄をその文で埋め直す）。欄は普通のエディタ（行番号・コードの書体・エディタの文字の大きさ・構文の色は無し）で、開いた時と見せる衝突が替わった時（解決・次へ・バッファの版が変わった）に**今の側**で埋め、フォーカスは欄へ。下のボタンは `結果で解決` と、帯と同じ（今の側 / 入ってくる側 / 両方 / 次へ ↓・warn の枠）と `閉じる`。`結果で解決`（欄の中の ⌘⏎ も）は印ごと衝突を欄の文に置き換える（空なら衝突ごと消す・最後に改行が無ければ足す・`<<<<<<<` の行が CRLF のファイルは CRLF で書く＝入ってくる側だけ CRLF の行があっても LF のファイルは LF のまま）。1 枚のボタンは**見せている衝突**に効く（欄の中の F8 や ⌃G で本体のキャレットが別の衝突へ動いても）。`次へ ↓` は見せている物の次（末尾の次は先頭）。どの解決も帯と同じ 1 回の編集（⌘Z 1 回で戻る）で、そのまま次の衝突を見せ、無くなれば閉じてエディタへ戻る。Esc で閉じる（欄の中でも・欄が複数カーソルなら先にそれを畳む）。開いた時のタブが前から外れた（別のタブを選ぶ・新しく開く・閉じる・プロジェクトを移る）・衝突が無くなった（外で書き換わった）時も、描かずに次の描画の前に閉じ、フォーカスはエディタへ。列の中身は開いた時・操作の後・バッファの版が変わった時に写す（描画のたびに全文を読まない）

### 5.1 ソース管理パネル（⌃⇧G・左ドック）

- **入力欄 = 平坦 EditorView**（composer・改名と同じ部品＝IME / ⌘V / ⌘Z が効く）。コミットメッセージは Enter で改行・**⌘⏎ でコミット**、内容に合わせて 1〜6 行で伸びる（空の間は placeholder）。＋（新しいブランチ）の間は 1 行の名前欄に替わり、枠がプロジェクト色・⏎ で作成・Esc で取消。Esc（名前欄でない時）はパネルを閉じる
- **変更の行を押すと HEAD との diff タブ**。右端の ＋ / − は stage / unstage だけ（行の押下へ伝えない）
- **コミット / push は repo のフックを走らせる**（pre-commit / commit-msg / pre-push）。フォルダを開いただけで走る自動の git（status / diff / log / worktree 作成など）は従来どおり `core.hooksPath=/dev/null` で封じる
- 失敗（コミット・stage・push・pull・PR・AI メッセージ・ブランチ作成）は §8 の失敗トースト。失敗したコミットのメッセージは消さない
- **⌘F 検索バー**（M10）: エディタ右上に浮かせるカード（bg2・枠 border・影）。行1 = ▸/▾（置換行開閉）+ クエリ + `n/m` + Aa + `.*` + ‹ › + ×。行2（⌥⌘F）= 置換 + [置換] [全置換]。アクティブ入力欄 = **アクセント枠 + 末尾キャレットバー**。**全マッチ = warn 16% 面**（選択面の下）・現在マッチ = 選択面（選択して見せる）。Enter/⇧Enter = 次/前、置換欄 Enter = 1件置換、⌘Enter = 全置換（1 undo）、Esc = 開いた位置へ戻って閉じる、× = 現在位置のまま閉じる
- **CSV / TSV の表**（O29・2026-09-26）: `.csv`（`,`）/ `.tsv`（タブ）は ⌘⇧V（パンくずのプレビュートグルも出る）で本文 ⇄ 表。読み方は RFC 4180（`"` で囲んだ欄の中の区切り・改行・`""`）。1 行目 = 見出し（bg2・太字・下線 1px・上に固定）、左端に行番号（fg2・右寄せ）、欄の間は縦線 1px（border）。列の幅は先頭 500 行の見た目の幅（全角 2）を 3〜40 文字に丸め、長い欄は `…` で切る（欄の中の改行は 1 行目だけ）。行は仮想リスト（行高 = 文字の大きさ × 1.7）で、横は列の合計幅でスクロール。読むのは先頭 20,000 行まで（超えたら上に `先頭の N 行だけを表にしています`・fg2）。書体はコードの書体。読むだけ（編集は本文）。表は本文の版で持ち直す
- **Markdown のスラッシュメニュー**（O29・2026-09-26）: Markdown の行頭（字下げは可）で `/` を打つと、補完と同じポップアップに形を並べる（種別の欄は `md`・右に説明 fg2）: h1 / h2 / h3 / bullet / numbered / todo / quote / code / table / divider / image / link / toc。続けて打つ英字で前方一致に絞り込み（`/co` → code）、⏎ / Tab で `/語` を形に置き換える（1 手＝⌘Z で `/語` に戻る）。キャレットは形の中の打つ所（code = ```` ``` ```` の後ろ＝言語名・table = 最初の欄・image / link = 括弧の中）。空白や記号を打つ・Esc で閉じる（`/` はそのまま残る）。行の途中の `/`（パス・日付）と Markdown 以外では出さない
- **横並びのライブプレビュー**（O29・2026-09-26・⌘K V・`editor::ToggleSidePreview`）: Markdown のエディタを左右に割り、左 = 本文（編集・キャレット・選択はここだけ）、右 = 整形プレビュー（⌘⇧V と同じ描画・同じブロックのキャッシュ＝打つたびに版が変わった時だけ読み直す）。間は縦線 1px（border）で、幅は半々。スクロールは左右で別（連動しない）。パンくずのプレビュートグルの右に Lucide `columns-2`（12px・ON で bg2 + fg0・OFF で fg2）。ON にすると ⌘⇧V の全面表示は解く（本文を見せる）。Markdown 以外では出さない。WYSIWYG は作らない
- **Markdown の整形プレビューの front matter と目次**（O29・2026-09-26）: 頭の `---` … `---`（YAML）/ `+++` … `+++`（TOML）は本文として読まず、プレビューの先頭に**プロパティの表**で出す（枠 1px border・角丸 6・キー = fg2・幅 120px・値 = fg1・本文より 0.5pt 小さい・入れ子や一覧は `a, b` に畳む）。閉じの行が無ければ front matter とみなさない。段落が `[toc]` / `[[toc]]` だけなら**目次**（見出し h1〜h4 を字下げで・fg1 → hover fg0・押すとその見出しが上に来るまで流す・見出しが無ければ「見出しがありません」）。プレビューのブロックはスクロールする要素の直下の子に並べ、行長は子ごとの max_w 860px で抑える
- **Finder からエディタへ落とす**（O29・2026-09-26）: 主ペイン・右の分割ペイン・タブが無い時の案内面が受ける（受け面の色は付けない）。**Markdown のエディタに画像だけ**を落とすと、`.md` と同じフォルダへコピー（project の中の画像はコピーせず指す・同名は `name-1.png` で避ける）して、**落とした所**（本文より上＝タブ・パンくずならキャレット）に `![名前](相対パス)` を入れる（1 枚 1 行・空白と括弧は `%20` / `%28` / `%29`・⌘Z 1 回で文が戻る）。それ以外（画像でない・Markdown でない・混ざる）は落としたファイルをタブで開く（フォルダは開かない）。SSH 先の project は受けずにトースト（エクスプローラへ落とすとアップロード）

- メタ行: model ピル・think ピル・**トークンメーター常時**（バー64px + `23.4k/200k` 数字。バー=スレッド色）
- transcript（VSCode Claude Code 拡張踏襲）:

- **起動してすぐ終了したカード（composer の直上・2026-09-27）**: エージェントのプロセスがセッションを開く前（initialize の前後）に終わったら、ACP の「Broken pipe」ではなく、エージェントが stderr に書いた末尾（最後の 40 行・1 行 1000 バイトまで・色などの制御文字は落とす）をカードで見せる。カード（bg2・枠 1px `border`・角 9・色相なし）: 見出し「起動してすぐ終了しました」（12px 太字 fg0）+ エージェント名（fg1）+ 右に文字チップ `再開` `閉じる`（セッション断の「再開」と同じ様式）、本文「終了コード 1。エージェントが stderr に最後に書いた行です（画面だけ・保存しません。渡した鍵などは伏せています）」（fg1 11.5px）、stderr の箱（bg1・枠・角 6・等幅 11px・高さ 160 まででスクロール・何も無ければ「（stderr には何も書かれていませんでした）」）。**stderr は画面だけ**: transcript（DB に保存される）に残す失敗の 1 行は「エージェントが起動してすぐ終了しました（終了コード 1）。…画面にだけ出し、保存しません」で stderr を含まない。ログにも書かない。エージェントへ渡した env のうち秘密らしい名前（KEY・TOKEN・SECRET・PASSWORD・AUTH・BEARER・COOKIE・HEADER 等の語を含む）の値と、よく知られた鍵の形（`sk-`・`ghp_`・`xoxb-`・`AKIA`・`AIza` 等）と `Bearer` の次の語は `••••` に伏せる。カードが出ている間はセッション断バナーを重ねない（閉じるとバナーに戻る）。次にセッションが開いたら消える
- **目標（`/goal`・O2）**: エージェントが目標を持っている間（ACP `session_info_update._meta.goal`・Codex / Claude）、composer の直上に 1 行 `目標  <目的>  <状態>` を常時出す。**目標への操作（O17・2026-09-26）**: エージェントが initialize の `_meta.goal`（`controlMethod`＝拡張メソッド・`actions`）で操作を広告していれば（Codex）、状態の右に文字チップ（セッション断の「再開」と同じ様式）: 進行中・止まっています → `一時停止` `取り消す` / 一時停止中・上限で停止 → `再開` `取り消す` / 達成 → `取り消す`。押すと拡張メソッドをターン中でも待たずに送り、結果はエージェントが送り直す目標の状態で映る（楽観的に書き換えない）。面はセッション断バナーと同じ（bg2・枠 1px・角 7）で**色は中立**、状態は文字（進行中 / 一時停止 / 止まっています / 達成 / 上限で停止）。目的は 1 行で切り、全文はツールチップ。null で消え、新しい会話では消す（引き継いだ会話はエージェントが送り直す）
- **セッション断バナー（composer の直上・2026-09-08）**: エージェントとの transport が閉じた（SSH 切断・プロセス終了）スレッドには、送信待ちと同じ様式のカード（bg2・枠 1px・角 7px）に、SSH 先で動かしている時は「セッションが切れました（SSH 切断など）。次の送信で立ち上げ直します」、**手元のエージェントなら「エージェントが終了しました。次の送信で立ち上げ直します」**（SSH と言わない・2026-09-27。ターンの途中で切れた時の transcript の 1 行も同じく手元は「エージェントのプロセスが終了しました」）+ 文字チップ **「再開」**（枠 1px・10.5px・アイコン禁止）。再開/次の送信でエージェントを立ち上げ直し、エージェントが `loadSession` を広告していれば前回の会話を `session/load` で引き継ぐ。結果は同じ場所に薄字（fg2・10.5px）で一言「前回の会話を引き継いで再開しました」/「新しいセッションを開始しました（前回の会話は引き継げませんでした）」と出し、次のターン開始で消す。切断は待機中でも検知する（送信して初めて分かる、をやめる）
- **質問カード（composer の直上・Elicitation）**: エージェントの選択肢つき質問（Claude の AskUserQuestion など・ACP form elicitation の選択式だけ）。面 bg2・枠 1px スレッド色 60%・角 9。質問文 → 選択肢チップ（選んだ物は枠スレッド色 + bg3）→ フッタ「これで回答」「答えない」。単一選択が 1 問だけのカードは押した瞬間に送る（「これで回答」を出さない）。複数選択はトグルして「これで回答」。**自由入力欄（O17・2026-09-26）**: 質問に Other 欄（`_meta._askUserQuestionCustomAnswer`）が付いていれば、選択肢の下に 1 行の入力欄（bg1・枠 1px・角 6。書くと枠がスレッド色）。placeholder は単一選択「自分で書く（案を選んだ時はその案に添えるメモになる）」/ 複数選択「自分で書く（選んだ案に足される）」。空白以外を書いた問いは答え済みに数え、書くと「これで回答」が出る。入力欄の Enter（IME の確定 Enter は除く）で確定し、フォーカスは composer へ戻る。書いた文字は Other 欄の名前で返し、選択と両方あれば両方返す（どう読むかはエージェント側）。スマホ（リモート管制）の質問にも同じ入力欄が出る（Other 欄つきの質問だけ・選ぶか書くかのどちらかが要る・ホストが検証する）

- タブの × は、前面でシェル以外のプロセスが動いている時だけ OS のダイアログ（`Window::prompt`・mac はシート）で「閉じる（⏎）/ キャンセル（Esc）」を確認する（O4）。判定は、前面を調べられる手元の端末（unix のシェル）では PTY の前面プロセスグループ ≠ シェル（`tcgetpgrp`）**だけ**（区切りは入れ子のプログラム＝ssh 先のシェルや `cat` した記録からも届き、シェルが前に戻っても「動いている」のまま残りうるので使わない）。前面を調べられない端末（Windows の ConPTY・リモートの `ssh -tt`＝前面は常に ssh 自身）は、シェルが出す区切り（OSC 133 / VS Code の OSC 633・O25 / C20・2026-09-26）でコマンドが動いている（C の後・D か次のプロンプト A / B の前）時。区切りは `pty_guard::GuardedPty` が本物の解析器より先に読む（EventLoop は触らない）。区切りも無ければ確認しない
- **リンク**（2026-09-26）: `path:line`（行番号つきだけ・クリックでエディタの行へ）と **URL**（`http(s)://`・スキーム無しの `localhost:3000` / `127.0.0.1:5173` / `[::1]:8080` は `http://` を補う・**OSC 8 のハイパーリンクは http / https だけ**・OSC 8 が文字から拾うものより優先）。下線 1px fg2、ホバーで fg0 + 指の形。**押して離した同じセルで開く**（ドラッグは選択）。URL は workspace の `open_terminal_url` 1 か所で既定ブラウザへ（localhost をアプリ内のプレビューで開く変更の差し替え口）
- **描画**: 下線の全種（単線・二重 `4:2`・波線 `4:3`・点線 `4:4`・破線 `4:5`・下線色 SGR 58）・取り消し線・DIM（不透明度 66%）・太字・斜体・反転。**カーソルはアプリの指定形**（ブロック / 下線 2px / 縦棒 2px / 中空）で fg1、フォーカスが無い時はブロックを輪郭・線は fg2、Hidden は描かない。**選択 = エディタの選択面色を背景色の後に重ねる**（色付きの背景の上でも見える）
- **⌘F 端末内検索**: エディタの ⌘F バーと同じ寸法（右上に浮かせる・幅 380・置換行なし・入力欄の枠とキャレット = プロジェクト色）。**入力欄は IME の正しい 1 行入力**（`EditorView`・12px・R12）＝日本語の変換・貼り付け・選択しての置き換え・カーソル移動が効く（キャレットはほかの 1 行入力と同じ幅 2px・行の高さで、点滅しない＝端末は出力が無ければ描き直さない。空の時はキャレットの右にプレースホルダ）。打つたびに探し直すが、**変換中は探さず確定で探す**（変換中の ⏎ は確定だけ・次へ進まない・欄に改行は入らない）。貼り付けは 1 行目だけ。scrollback を含めて数え `n/m`（1000 超は `+`）、一致 = warn 16%・いまの一致 = 選択面色。⏎ / ⇧⏎ = 次 / 前（`›` / `‹`）・Aa = 大小を区別・`.*` = 正規表現（誤りは件数の位置に err 色）・esc = 開いた位置へ戻って閉じる・× = その位置のまま閉じる。欄の中の ⌘C / ⌘V / ⌘A は入力欄の物（⌘C は欄に選択が無ければ端末の選択）、⌘F / ⌘K / ⌘T / ⌘W / ⌘\ は欄の中でも端末の物（入力欄の `Editor` は `Terminal` より深く、そのままでは全域の束が先に当たるので、端末の束を照合の前に受ける）。1 行の選択があれば語の初期値
- **右クリックメニュー**: コピー（選択が無ければ押せない）/ 貼り付け / すべて選択 / ─ / クリア / 検索。タブ・エクスプローラのメニューと同じ部品（幅 220・bg2・角丸 8）に、その OS のキーを右に fg2 で添える
- **マウス**: アプリがマウスの報告（1000 / 1002 / 1003）を有効にしたら、クリック・ドラッグ・ホイールはアプリへ（SGR 1006 優先）。**⇧ を押している間は従来どおり選択・メニュー**。ダブルクリック = 語、トリプル = 行の選択。フォーカスの出入りは FOCUS_IN_OUT（1004）のアプリへ `CSI I` / `CSI O`
- **キー**: ⇧⏎ = 改行（kitty なしは `ESC CR`・kitty keyboard protocol を push したアプリには `CSI 13;2u`）。⌥ = Meta（`ESC` 前置。ドイツ配列の ⌥L = `@`・JIS の ⌥¥ = `\` のように**配列が ASCII の記号を作った時は記号**）。修飾付きの矢印 / Home / End / Delete / PageUp / PageDown / F1〜F12 は xterm の `CSI 1;<mod>X`。テンキーの APP_KEYPAD は GPUI がテンキーを区別しないので未対応
- **ドロップ**: Finder / エクスプローラからのドロップで、シェル向けに引用したパス（空白区切り・末尾に空白）を貼り付けの経路（bracketed paste）で入れる。貼り付けは囲みを抜け出す ESC を落とし、囲みが無い時は改行を CR にそろえる
- OSC 52 はコピー（書き込み）だけ受ける・読み出しは拒否。ベルは窓が後ろにある時だけ知らせる（Dock のアイコン）
- 通知はトースト（右下・5 秒・最大 4 枚・幅 520px で折り返す）。エージェント完了は宛先チップと同じ書式で「●rope設計 完了」（止めた / 拒否されたターンは「中断」、エラーで終わったターン・起動に失敗したエージェントは「失敗」）。承認待ちと**質問待ち**（Elicitation・O12）は同じ扱い: トースト（クリックでそのスレッドへ）・statusbar の待ち表示・要対応（質問カード = 質問文 + 待ち時間 +「開いて答える」で没入。選択肢はスレッドのカードで選ぶ）・`◐N`・Task を Blocked へ（質問だけで止まった Task の「次へ」は「答える」）
- **失敗のトースト**（git / gh の失敗・設定を保存できない等）: 1 行目 = 何ができなかったか、2 行目以降 = 理由の要点（git の出力から `hint:` 行と空行を落とした先頭 3 行・240 字まで）。読む時間が要るので 12 秒。要点に収まらない出力（フックの出力など）は右端に `全文 ›`（fg2）を出し、押すと `<command> の出力` の読み取り専用タブで全文を開く。設定の保存は「settings.json を読めないので保存しませんでした（理由）」— 読めないファイルは上書きしない
- **OS の通知**（O12・GPUI `show_system_notification`）: ターンの完了 / 中断 / 失敗・承認待ち・質問待ちを、**その窓を見ていない時だけ**出す。「見ている」= アプリの前面の窓（`cx.active_window()`）がこの窓で、**かつ** OS のキー窓（`Window::is_window_active` を `observe_window_activation` で即時に写した `window_active`）＝別の窓・別のアプリ・隠している・最小化している時は出す（macOS の前面の窓 `NSApp.mainWindow` は隠しても空になるとは限らず、隠している間は描画も止まるので render での更新だけでは古い値が残る・R15）。見ている時はトーストで足りる。題 =「完了: スレッド名」等、本文 =「プロジェクト（Task）名 — 最後の発言の末尾 / 何の許可か / 質問文」。tag = スレッドの永続 id（同じスレッドは置き換え＝積まない）。押す = 隠していれば戻し（macOS は `NSApplication.unhide`）アプリを前へ + `jump_to_thread`（Chat はそのチャットへ）。スレッドのミュート（DB に保存＝再起動で消えない）と設定 `system_notifications` を守る。Captain の完了だけは出さない（自分で起きた采配の結果・失敗/承認/質問は出す）
- **Dock バッジ**（O12・macOS・objc2-app-kit で `NSApplication.dockTile.badgeLabel`）: 要対応の件数（`◐N` と同じ数え方 = Blocked のスレッド + Failed の Task + 裁いていない Captain の分解案）を**全窓の合計**で出す。0 は消す。数え直しはスレッドの状態台帳（`RunningRegistry`）の更新と Task の phase 遷移のたび（Chat のスレッドは `◐N` と同じく数えない）
- **作業中はスリープさせない**（O13・設定 `keep_awake`・既定 `"working"`）: 作業中（Working）のスレッドが**全窓で 1 本でもある間だけ**、放っておいた時のスリープ（idle sleep）を止め、0 本になったら放す。承認待ち・質問待ち（Blocked）は数えない（人の返事を待つ間まで起こし続けない）。画面は普通に消え、自分で選んだスリープとノートの蓋を閉じた時のスリープは止めない。電池の時も掴む（掴む長さはターンの長さで頭打ち）。mac = `caffeinate -i -w <necoder の pid>`（necoder が落ちても一緒に抜ける）、Windows = `SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED)`。ほかの OS は何もせず設定の行も出さない。数え直しは `RunningRegistry` と設定の変化のたび（Dock バッジと同じ経路）。画面には何も出さない（設定 › 動作とエディタ の 1 行だけ）
- **エージェント状態（herdr 参照・状態検知は ACP ネイティブ＝ヒューリスティック不要）**: ACP のライフサイクルから `ThreadActivity` を導出する。**Blocked**=`session/request_permission` 待ち（ターンが実際にブロック）/ **Working**=ストリーミング中 / **Done**=直近ターン完了・**未確認**（見るまで残るラッチ・中断= `StopReason` の Refusal/Cancelled は注意表示）/ **Idle**=待機。ambient 表示先は タブ/List・titlebar beacon・statusbar 中央ロールアップ・**レールの静止ドット（他プロジェクトの Blocked/Done・右上。Working は省く）**・⌘O ダッシュボード。ロールアップ優先度 Blocked>Working>Done>Idle。全窓横断の台帳は `RunningRegistry`（worktree root → 状態）

## 14. 変更レビュー（Review）

worktree の変更を 1 画面で読む面。エディタのタブ（パレット「Git: 変更をレビュー」・ソース管理パネルの「⇄ 変更をレビュー」）と、
Fleet の Task カードの「変更」サイドペイン（Task 見出しの右のトグル・会話の横に開く・FLEET-V2 §3.5）が **session ごとに同じ 1 枚**を載せる（Editor と Fleet は同時に描かないので、開いた畳み・見た印が揃う）。
エディタのコア（`editor_view`）は拡張しない。行の間にブロックを差し込む口も任意色の行背景も無いので、可変高の仮想リスト
（`crates/review_view`）に「ファイル見出し / 行 / 畳み / お知らせ」を並べる独立したビューにした（依存方向 = コアは機能を知らない）。

| 領域 | 仕様 |
|---|---|
| ツールバー（高さ 34・bg0・下罫線） | `☰`（ツリーの表示切替）/ `比較` + 基準チップ（押すとメニュー）/ `空白を無視`（`git diff -w`・ON は accent-dim の面）/ 右寄せ `N ファイル +A −D`（数字は ok / err）/ `↻`（読み直し）。作業ツリーが変わると `↻ 新しい変更があります`（枠 1px）に変わる — **自動では読み直さない**（読んでいる行を動かさない） |

- 読み直しても、開いた畳み・見た印・スクロール位置（同じ行）は保つ。ただし**見た印は「見た時の比較の基準 + そのファイルの差分の指紋」に結び付く**（R01）: 同じ基準で差分が変わっていたら印を外し、畳みを開いて見出しに `見た後に変更あり`（ツリーは `↻ +N −M`・warn）。基準を切り替えただけなら印は残る（戻せば復活）

## 15. リモート管制（スマホの PWA・control.necoder.com・2026-10-01）

- 画面は 2 枚: **一覧**（共有中の全プロジェクトのスレッド）→ タップで **会話**。戻るはヘッダの ‹ と端のスワイプ（history）。アプリを開き直した時は前回の会話へ戻す（iOS は裏の PWA をよく破棄する）。PC の切替・再接続・通知・言語・接続の削除は**設定シート**へ寄せ、画面の上端には置かない
- 一覧: 上端バー = `necoder` + PC 名・接続状態（ドット ok / warn(脈動) / err）・設定。**要対応**（承認・質問待ち）を先頭に別枠で出し（プロジェクト名を色の縦棒つきで添える）、プロジェクトは動いている順（回答待ち・実行中 → 新着 → その他。同じ順位の中はレール順）。プロジェクトの塊は左端のプロジェクト色の縦線 3px で見出しから最後の行までつなぐ。行 = 状態の印 + 名前 + トークン概数 / エージェント・状態語（太字のみ・色相なし）/ digest 2 行。見出しの右端 ＋ = 新規スレッド（エージェントを選ぶシート）
- 状態の印（§1.3 と同じ規律・色相は常にスレッド色）: 回答待ち `◐` 速い脈動 / 実行中 点字スピナー / **新着** `○`（その端末で最後に見たターンから進んで止まった）/ 待機 `●` 淡 / 切断 `○` 淡
