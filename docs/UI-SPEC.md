### 1.2 アイデンティティ色

- **プロジェクト色パレット（自動巡回）**: indigo `#7c8cf8` → teal `#34d3b6` → amber `#f0a24b` → rose `#ef7d9b` → green `#85c46c`

- 任意 hex はエスケープハッチ: §1.3 の流れ先（許可リスト）は変えない。**細い accent としての可読性はユーザー責任**（Peacock と違いコントラスト自動計算はしない）
- **スレッド色パレット（自動巡回）**: `#61afef` → `#e5c07b` → `#c678dd`（プロジェクト色と独立）
- accent-dim = プロジェクト色 16% 透過（パレット選択面・タイル選択輪郭のみ）

## 2. レール（プロジェクトの方向感覚・常設）

- 項目 = 30×30 角丸8。中身は優先順: `.necoder/settings.json` の `icon`（絵文字 or 画像パス）> 規約パス `.necoder/icon.png`（jpg/jpeg/webp も可・置くだけで効く）> プロジェクト名の頭文字（例: 印）。画像でも**色の枠は残す**（識別は色・画像は装飾＝§1.3）
- 状態: active = プロジェクト色の枠 + 2px リング / hover = 枠のみ / 通常 = 色 14% の面 + 35% の枠
- 下部に**実行中スレッドのドット**（5px・スレッド色・実行中 pulse 1.6s）→ 他プロジェクトの動きが常に見える
- ＋ = **統一オープン**（`open_launcher`）: フォルダ / ファイル / リモート + **最近（local + remote 混在・opened_at 降順）** を 1 枚の広いファジー面に。最近行は ●識別色 ＋ 実行中ドット、リモートは `host:path` で識別。⏎ = 現レールに開く。⌘O は開いているプロジェクト間の切替（別物）。左クリック = 窓内切替（ARCHITECTURE §5）。ドラッグ並び替えは v1
- **右クリック = コンテキストメニュー**（M10-2）: 色スウォッチ + 「その他の色…」（フル hex ピッカー）／新しいウィンドウで開く／**パスをコピー・ブランチ名をコピー**（O21・ブランチが分かる時だけ・写したらトースト「コピーしました: …」）／レールから外す／(worktree タブのみ) worktree を削除・worktree ごとブランチを削除。破壊的操作は二段確認（もう一度クリックで実行）
- **アクティビティアイコン**（下部・explorer/search/git/todos/agent/terminal/remote）: 表示中のビュー/ドックだけプロジェクト色・他は fg2（§1.3・VSCode の Activity Bar 準拠）。active 判定 = explorer:左ドックがツリー / search:検索パネル開 / git:git パネル開 / todos:板開 / agent:右ドック表示 / terminal:下ドック表示 / **remote:SSH ホストピッカーを開くアクション（server アイコン・アクティブプロジェクトがリモートなら色付き・#2）**
- **リモート slot**（レールのプロジェクト）: SSH 接続先はモノグラム右下に **server バッジ**（プロジェクト色・ローカルと見分ける・#2）。窓縁 2px 枠（§1.3）と併用
- **レールを押すと ↑/↓ でプロジェクトを流せる**（2026-09-12・旧「レール = 最後に触った面」を置換）: レールのどこか（項目でも空き地でも）を押すと**レールにフォーカスが移り**、面が bg2 に上がる（bg1 は実機で差が小さかったため強めた）。フォーカスがある間だけ **素の ↑/↓ が前後のプロジェクト切替**（⌃⌘↑↓ と同じ循環・行き先名フラッシュあり）。切り替えてもフォーカスはレールに残る＝連打で流せる。**Escape** で作業面へ戻り、レール外をどこか押しても戻る。トラックパッドで「突いて ↑↓」の動線
  - 素の ↑/↓ は keymap ではなく `on_rail_key_down` で受ける。gpui はコンテキスト無しのバインドを**最深**として解決するので、keymap に足すとエディタのキャレット移動を全域で殺す。Workspace コンテキストへ足すと逆に Editor より浅くて負ける
  - **⌘{ ⌘} の付け替えは廃止**（旧仕様。押した履歴でキーの意味が変わる隠れモードだった）。⌘{ ⌘} は常にエディタタブ切替
  - レールにフォーカスがある間は **Editor コンテキストの束（⌘S・⌘Z・⌘C/⌘V 等）が効かない**。左ドックや git パネルにフォーカスがあるときと同じ挙動で、Escape かクリックで戻れば復帰する

## 3. titlebar / statusbar

- titlebar: 信号機 → **ピル**（枠1px・左縁3pxプロジェクト色。名前クリック=⌘O、`⎇ branch ▾` クリック=branch/worktree メニュー）→ spacer → **beacons**（アクティブ project のスレッド、色ドット+名、実行中 pulse）→ **ベル**（通知の履歴）→ SSH → ドック開閉アイコン×3
- **ベル = 通知の履歴**（O13・Lucide `bell` 17px）: エージェントの完了 / 中断 / 失敗 / 承認待ち / 質問待ちを、この窓の分だけ最新 100 件残す（起動中だけ・ミュートしたスレッドは残さない・OS の通知の設定や「見ているか」に関わらず残す）。未読があればベルは fg0 + 右上に件数（中立の面 bg3・枠 border・9px・識別色は使わない）、無ければ fg2。押す / パレット「通知: 履歴を開く」= titlebar の右下に吊るす一覧（幅 380・最大 440 でスクロール・bg2・Esc / 外側クリックで閉じる）。見出し「通知の履歴」+ 未読がある時だけ「すべて既読」。行（新しい順）= スレッド色のドット（識別）+ 題（OS の通知と同じ「完了: スレッド名」等・未読は fg0 の太字 / 既読は fg1）+ 本文 2 行（fg2）+ 相対時刻 + 右端の ● / ○（未読 / 既読・押すと入れ替え）。行を押す = 既読にしてそのスレッドへ（OS の通知を押した時と同じ `jump_to_notified_thread`・閉じたスレッドなら既読にするだけ）
- statusbar（登録式・左→右）: `⎇ branch`・診断（Lucide `circle-x` n `triangle-alert` n＝文字グリフは使わない。click で診断一覧）・**ターミナル切替ボタン**（`square-terminal`・レール/⌃` と同じ `toggle_terminal`・開いている間は bg3 で灯す。診断→ターミナルの動線・2026-09-03）・LSP 状態 / **中央=状態の常設ロールアップ**（herdr 本来の形＝ニュースティッカーではない。ウィンドウのレール全プロジェクトを `RunningRegistry` から集計し「N 実行 · M 承認待ち · K 完了」+ 最重要スレッドを状態ドット付きで・click で該当プロジェクト+Agent へ）/ 拡張アイテム・**更新チップ**（新版あり「⬆ vX に更新」click → 更新中は文言が「ダウンロード中 NN% → 署名を検証中 → 差し替え中」と進み、下に 96×3px の進捗バー（溝 bg3・fg1 が伸びる・色相は使わない）→ 差し替え済みは「⟳ 再起動して vX へ」click で自プロセス終了待ちの relauncher を切り離してから通常 Quit・2026-09-03）・カーソル位置・エンコーディング・言語。**SSH チップ = 接続状態**（remote プロジェクトのとき・左群の色スウォッチ直後・2026-09-08）: 「SSH」の色が状態＝接続済み `ok` / 接続中 `warn` / 切断 `err` / 未接続（遅延接続でまだ触っていない）`fg2`。接続済み以外は状態の語（接続中… / 切断 / 未接続）を fg2 で添え、切断・未接続には文字チップ **「再接続」/「接続」**（枠 1px・10.5px・アイコン禁止）。click で host に今すぐ張り直しを頼む（heartbeat の最大 60s バックオフを待たない・生きている接続は捨てない）。状態は host の atomic を読むだけで、変化は購読（`remote_connection.rs`）が notify する＝ UI スレッドで SSH を待たない

- **使用量チップ**（O11・2026-09-26）: statusbar 右側の先頭。いまのスレッドのエージェントが知らせてきたレート制限を `5h 42% · 週 18%`（en `5h 42% · 7d 18%`）で出す。並べるのは 5 時間枠・週枠と、**80% 以上**（表示の整数 % で判定＝見えている数字と食い違わない）になったその他の窓（例 `Opus 週 83%`）。リセット時刻を過ぎた窓は出さず、値の無いエージェントではチップごと出さない。80% 以上の窓があれば文字を `warn` + Lucide `triangle-alert`、上限に達して止められている（Claude の `rejected`・リセット前）なら `err` + `circle-x`。診断の ▲ / ⊗ と同じ意味色とアイコンで、色だけに頼らない（エージェントの**活動状態**ではなくアカウントの警告なので、§1.3 の「状態に色相を使わない」には当たらないと判断・SSH チップ / クラッシュ通知と同じ扱い）。ツールチップ「<agent> の使用量（最後に受け取った値）。クリックで詳細」
- **使用量のポップオーバー**（チップのクリック / パレット「使用量: レート制限を表示」）: statusbar の真上に幅 440 のカード（bg2・枠 1px・角 8・影）。値は **エージェント + 動かしている場所（手元 / SSH 先）+ 認証の置き場（設定の `CLAUDE_CONFIG_DIR` / `CODEX_HOME`）** ごとに分けて持ち、混ぜない（R08）。見出しは `Claude Code` / `Claude Code · dev-box` / `Claude Code · ~/.claude-work`。チップはいまのスレッドの鍵の値だけを出す。エージェントごとに見出し（名前 12px 太字・`上限が近い`(warn) / `上限に達しています`(err)・右寄せ `受信 N分前`）+ 窓の行（名前 104px・使用率のバー 64×4px＝溝 bg3・伸びる側 fg1、80% 以上 warn・上限 err・`42%`・`あと 2 時間 13 分でリセット`）。他の窓より古い値の窓は行に `受信 N分前` を添える。いまのスレッドのエージェントが先頭。下に「値はエージェントが知らせてきた時にだけ変わります。ここに出ているのは最後に受け取った値です。」と文字チップ「統計を開く」。**Codex** は ACP で知らせてこないので、ポップオーバーを開いた時だけ `codex app-server` の `account/rateLimits/read` を 1 回呼ぶ（認証は codex 本体・60 秒以内の開き直しでは呼ばない・見出しの「再読み込み」で強制）。読み込み中 / 失敗は 1 行の fg2。外側クリック / Esc で閉じる。値は保存しない（再起動後はエージェントが知らせるまで何も出ない）。チップは値が無いと出ないので、パレットからも開ける（Codex の値を読む入口）
- **使用量の統計**（パレット「使用量: 統計を開く」）: About と同じ器のモーダル（幅 660・最大高 620・本文スクロール・枠 border）。直近 30 日（今日を含む・日付の境目はローカルの 0 時）の、台帳 `turn_usage` の日付 × エージェント。列 = 日付 / エージェント / ターン / トークン（棒 56×4px は中立＝溝 bg3・伸びる側 fg2、その期間の最大に対する割合）/ コスト（USD・報告が無ければ `—`）。先頭に 30 日の合計（fg0）。下に「推定値・Codex はコストを報告しない・ローカルのログは読まない」の注記。necoder で記録したターンだけ（`~/.claude` 等の JSONL は読まない）

## 4. エクスプローラ（3ビュー + ファイルブラウザ挙動）

- ヘッダ = **上位階層ブレッドクラム**（`Work › experience › necoder`、現在=太字 fg0、親=fg2・クリックで上へ。プロジェクトの外に出たら「フォルダブラウズモード」— 任意フォルダを右クリック→プロジェクトとして開ける）+ 右端に **更新ボタン**（Lucide `refresh-cw` 12px・fg2 → hover fg0/bg3。ツリー再構築 + git 色 + gutter diff を読み直す。監視の取りこぼし（エージェントが作ったファイル等）の明示的な逃げ道・2026-09-03）
- フッタ = ビュー切替アイコン3種（ツリー/カラム/アイコン）+「表示モード」ラベル
- **ファイルタイプアイコン**（3ビュー共通・`file_icon_path`）: 拡張子/名前から SVG アイコンを引く。言語ロゴ = **Simple Icons**（CC0・rust/js/ts/tsx/py/go/json/yaml/toml/html/css/md/shell/c/cpp/git/docker）、フォルダ・汎用 = **Lucide**（ISC・folder/folder-open/file/text/image）。すべて**単色マスク**で描き、色は `file_type_color`（syntax パレット）で薄く付ける＝**形で見分け、色は識別に集約**（多色ロゴにはしない）。フォルダは開閉で folder/folder-open を切替（ツリーは `is_expanded`・カラムは選択経路上）。未知拡張子は汎用ファイルへフォールバック
- **ツリー**: 行 = chev(10px) + **ファイルアイコン(14px)** + 名前 + git ドット（右寄せ・mod=warn色/add=ok色）。インデント 14px/段。選択 = bg3 + 左バー2pxプロジェクト色。並びはフォルダが先 → **自然順**（`file2` < `file10`・`9` < `99` < `100`・大文字小文字は無視。D16。⌘P の元の並びも同じ）。**行は仮想化**（`uniform_list`・見えている範囲の行だけを描く。D25）: 横スクロールの幅は「インデント + 名前」が最長の行で測り、命名の入力行は始めた時に見える位置へスクロールする
- **カラム**（Miller）: 列 150px 固定・最終列 flex。選択経路 = bg3+左バー。下部パスバー 26px

- **リソース**（パレット「リソース: メモリとプロセス」・O22 の Resource Manager の手元の分）: 中央モーダル（幅 560・最大高 520・bg2）。見出し `リソース（メモリ）` + `↻`。1 行目 = `necoder 本体 290 MB · 子プロセス 3.2 GB（N 本）`。続いてレールの順にプロジェクト / Task ごとの節: ● プロジェクト色 + 名前 + 合計 + **`使っていないエージェントを止める（N）`**（止められるものがある時だけ）。節の中は necoder の**直接の子**ごと（エージェントのラッパー・端末のシェル・LSP 等）に `コマンド（pid・N プロセス）` と子孫を含めた RSS。作業フォルダがどこにも入らない物は最後の `プロジェクトの外`。止めるのは idle の回収弁と同じ条件（静かで会話を引き継げるスレッドのエージェントだけ・会話は残り次の送信で `session/load`・シグナルは送らない）。端末・開発サーバはここでは止めない。読むのは開いた時と ↻ の時だけ（`ps -o pid,ppid,rss,comm` と `lsof -d cwd` を 1 回ずつ）。SSH 先と Windows は未対応

## 8. ターミナル / 通知

- 下ドック 既定 240px（上縁ドラッグで 60〜900 可変・ニュース/ターミナルで共有）。タブ（active = bg1。色線なし）+ `＋`。**タブ名 = アプリが付けたタイトル**（OSC 0 / 2・`✳ Claude Code` など・1 行目だけ・幅 220px で省略）、無ければ「ターミナル N」。プロンプト = ok 色
- タブの × は、前面でシェル以外のプロセスが動いている時だけ OS のダイアログ（`Window::prompt`・mac はシート）で「閉じる（⏎）/ キャンセル（Esc）」を確認する（O4）。判定は PTY の前面プロセスグループ ≠ シェル（`tcgetpgrp`）。調べられない端末（Windows の ConPTY・リモートの `ssh -tt`）は確認しない
- **リンク**（2026-09-26）: `path:line`（行番号つきだけ・クリックでエディタの行へ）と **URL**（`http(s)://`・スキーム無しの `localhost:3000` / `127.0.0.1:5173` / `[::1]:8080` は `http://` を補う・**OSC 8 のハイパーリンクは http / https だけ**・OSC 8 が文字から拾うものより優先）。下線 1px fg2、ホバーで fg0 + 指の形。**押して離した同じセルで開く**（ドラッグは選択）。URL は workspace の `open_terminal_url` 1 か所で既定ブラウザへ（localhost をアプリ内のプレビューで開く変更の差し替え口）
- **描画**: 下線の全種（単線・二重 `4:2`・波線 `4:3`・点線 `4:4`・破線 `4:5`・下線色 SGR 58）・取り消し線・DIM（不透明度 66%）・太字・斜体・反転。**カーソルはアプリの指定形**（ブロック / 下線 2px / 縦棒 2px / 中空）で fg1、フォーカスが無い時はブロックを輪郭・線は fg2、Hidden は描かない。**選択 = エディタの選択面色を背景色の後に重ねる**（色付きの背景の上でも見える）
- **⌘F 端末内検索**: エディタの ⌘F バーと同じ部品（右上に浮かせる・幅 380・置換行なし・入力欄の枠とキャレット = プロジェクト色）。scrollback を含めて数え `n/m`（1000 超は `+`）、一致 = warn 16%・いまの一致 = 選択面色。⏎ / ⇧⏎ = 次 / 前（`›` / `‹`）・Aa = 大小を区別・`.*` = 正規表現（誤りは件数の位置に err 色）・esc = 開いた位置へ戻って閉じる・× = その位置のまま閉じる。1 行の選択があれば語の初期値
- **右クリックメニュー**: コピー（選択が無ければ押せない）/ 貼り付け / すべて選択 / ─ / クリア / 検索。タブ・エクスプローラのメニューと同じ部品（幅 220・bg2・角丸 8）に、その OS のキーを右に fg2 で添える
- **マウス**: アプリがマウスの報告（1000 / 1002 / 1003）を有効にしたら、クリック・ドラッグ・ホイールはアプリへ（SGR 1006 優先）。**⇧ を押している間は従来どおり選択・メニュー**。ダブルクリック = 語、トリプル = 行の選択。フォーカスの出入りは FOCUS_IN_OUT（1004）のアプリへ `CSI I` / `CSI O`
- **キー**: ⇧⏎ = 改行（kitty なしは `ESC CR`・kitty keyboard protocol を push したアプリには `CSI 13;2u`）。⌥ = Meta（`ESC` 前置。ドイツ配列の ⌥L = `@`・JIS の ⌥¥ = `\` のように**配列が ASCII の記号を作った時は記号**）。修飾付きの矢印 / Home / End / Delete / PageUp / PageDown / F1〜F12 は xterm の `CSI 1;<mod>X`。テンキーの APP_KEYPAD は GPUI がテンキーを区別しないので未対応
- **ドロップ**: Finder / エクスプローラからのドロップで、シェル向けに引用したパス（空白区切り・末尾に空白）を貼り付けの経路（bracketed paste）で入れる。貼り付けは囲みを抜け出す ESC を落とし、囲みが無い時は改行を CR にそろえる
- OSC 52 はコピー（書き込み）だけ受ける・読み出しは拒否。ベルは窓が後ろにある時だけ知らせる（Dock のアイコン）
- 通知はトースト（右下・5 秒・最大 4 枚・幅 520px で折り返す）。エージェント完了は宛先チップと同じ書式で「●rope設計 完了」。承認待ちと**質問待ち**（Elicitation・O12）は同じ扱い: トースト（クリックでそのスレッドへ）・statusbar の待ち表示・要対応（質問カード = 質問文 + 待ち時間 +「開いて答える」で没入。選択肢はスレッドのカードで選ぶ）・`◐N`・Task を Blocked へ（質問だけで止まった Task の「次へ」は「答える」）
- **失敗のトースト**（git / gh の失敗・設定を保存できない等）: 1 行目 = 何ができなかったか、2 行目以降 = 理由の要点（git の出力から `hint:` 行と空行を落とした先頭 3 行・240 字まで）。読む時間が要るので 12 秒。要点に収まらない出力（フックの出力など）は右端に `全文 ›`（fg2）を出し、押すと `<command> の出力` の読み取り専用タブで全文を開く。設定の保存は「settings.json を読めないので保存しませんでした（理由）」— 読めないファイルは上書きしない
- **OS の通知**（O12・GPUI `show_system_notification`）: ターンの完了 / 中断 / 失敗・承認待ち・質問待ちを、**その窓を見ていない時だけ**（`cx.active_window()` がこの窓でない＝別の窓・別のアプリ・隠している）出す。見ている時はトーストで足りる。題 =「完了: スレッド名」等、本文 =「プロジェクト（Task）名 — 最後の発言の末尾 / 何の許可か / 質問文」。tag = スレッドの永続 id（同じスレッドは置き換え＝積まない）。押す = アプリを前へ + `jump_to_thread`（Chat はそのチャットへ）。スレッドのミュート（DB に保存＝再起動で消えない）と設定 `system_notifications` を守る。Captain の完了だけは出さない（自分で起きた采配の結果・失敗/承認/質問は出す）
- **Dock バッジ**（O12・macOS・objc2-app-kit で `NSApplication.dockTile.badgeLabel`）: 要対応の件数（`◐N` と同じ数え方 = Blocked のスレッド + Failed の Task）を**全窓の合計**で出す。0 は消す。数え直しはスレッドの状態台帳（`RunningRegistry`）の更新と Task の phase 遷移のたび（Chat のスレッドは `◐N` と同じく数えない）
- **作業中はスリープさせない**（O13・設定 `keep_awake`・既定 `"working"`）: 作業中（Working）のスレッドが**全窓で 1 本でもある間だけ**、放っておいた時のスリープ（idle sleep）を止め、0 本になったら放す。承認待ち・質問待ち（Blocked）は数えない（人の返事を待つ間まで起こし続けない）。画面は普通に消え、自分で選んだスリープとノートの蓋を閉じた時のスリープは止めない。電池の時も掴む（掴む長さはターンの長さで頭打ち）。mac = `caffeinate -i -w <necoder の pid>`（necoder が落ちても一緒に抜ける）、Windows = `SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED)`。ほかの OS は何もせず設定の行も出さない。数え直しは `RunningRegistry` と設定の変化のたび（Dock バッジと同じ経路）。画面には何も出さない（設定 › 動作とエディタ の 1 行だけ）
- **エージェント状態（herdr 参照・状態検知は ACP ネイティブ＝ヒューリスティック不要）**: ACP のライフサイクルから `ThreadActivity` を導出する。**Blocked**=`session/request_permission` 待ち（ターンが実際にブロック）/ **Working**=ストリーミング中 / **Done**=直近ターン完了・**未確認**（見るまで残るラッチ・中断= `StopReason` の Refusal/Cancelled は注意表示）/ **Idle**=待機。ambient 表示先は タブ/List・titlebar beacon・statusbar 中央ロールアップ・**レールの静止ドット（他プロジェクトの Blocked/Done・右上。Working は省く）**・⌘O ダッシュボード。ロールアップ優先度 Blocked>Working>Done>Idle。全窓横断の台帳は `RunningRegistry`（worktree root → 状態）

  |---|---|---|

  | Task を終了 | 台帳を `archived` に。編隊/herd から消える | worktree（ディスク） |
  | worktree を削除 ⚠ | `git worktree remove` | ブランチ |
  | ブランチごと削除 ⚠ | worktree + `git branch -D` | なし |

  下 2 段は**確認ダイアログ**（次項）。実装はレールの `delete_slot_worktree_impl` へ委譲 ＝ **どこから消しても同じことが起きる**
- **worktree 削除の確認ダイアログ（2026-07-27）**: 「本当に消しますか？」は情報がゼロなので出さない。出すのは **git に数えさせた「失うもの」**:
  - `未コミットの変更 N ファイル — git にも残らず、元に戻せません`（`git status`）
  - `統合先に入っていないコミット N 件`（`git rev-list --count <integration>..HEAD`。比較先が引けなければ「比較できませんでした」と正直に出す）
  - ブランチごと削除なら `ブランチ <name> も削除します`
  - どれも 0 なら `失うものはありません（同じブランチから作り直せます）`
  0 件の行は出さない（0 を並べても読ませるだけ）。背景クリック / キャンセルで閉じ、**閉じる側は絶対に実行しない**
- **「次回から確認しない」は取り返しがつく削除にだけ効く**（`confirm_worktree_delete`）。未コミットの変更は reflog でも戻らないので、
  そこを 1 個のチェックボックスで無音化できるようにはしない。チェックボックスのラベルでその条件を明示する
- 旧・二段確認（同じ行をもう一度押させる）は**廃止**。押させる回数を増やしても情報は増えない
- **× は「閉じる」だけ**で、Task もエージェントも消さない。閉じた時にエージェントが走っていたら**トーストでそう言う**（黙って裏で走らせない）
- **セルは初回だけ自動配置**（`fleet_seeded`）。「空なら seed」だと最後の 1 枚を × した次のフレームに全セルが復活していた（2026-07-27 修正）
- **拡大は ⤢ の明示操作にだけ属する**。herd / グラフのタップは**拡大しない**（以前は必ず全画面になっていた）。既に拡大中なら枠を保ったまま対象だけ差し替える
- **linked worktree の判定は git に聞く**（2026-07-27）。「このセッションで worktree として開いたか」の記憶に頼っていたため、再起動すると worktree なのに削除メニューが消えていた
- **履歴（前の会話の復元）**: スレッドは DB 永続なので、編隊でも Agent パネルと同じ**スレッド履歴 Picker**（**アクティブプロジェクトのみ**・アーカイブ含む・detail に Σトークン＋開始/最終入力の相対時刻）から復元できる（＋タイル「履歴から復元」/ ⌘⇧T は直近）。編隊モード中に確定した会話は**グリッドのセルとして前面（拡大）に出る**。相対時刻は編隊/herd 表示中のみ 30 秒時計で更新（両方閉じたら自停止＝idle 予算）
- **Task lifecycle / integration**: planned → working / blocked → review_ready → merge_ready → integrating → integrated。Review は read-only Conflict Radar、main への write は明示 Integrate のみ。
- **編隊操作 API**: `necoder fleet create/list/status/wait/review/integrate` と同等 MCP tools。stable Task ledger を真実にするため Captain/UI の再起動を跨いで wait/resume できる。詳細は `FLEET-ARCHITECTURE.md`。
- 既存の**スレッド色貫通・宛先チップ・トークン常時表示**は編隊内でも不変。**キー**: 編隊トグル / ＋(パネル追加) / グラフ ⌄(折り畳み) / セルフォーカス(クリック)（既定キーは M14 で確定）

- **MCP ページ**: 見出しの下に **「N 件中 M 件有効」** + 絞り込みチップ（すべて / necoder の設定 / Codex CLI / Claude Code / Cursor — **実際に 1 件以上ある出所だけ**出す）+ **「有効のみ」**チップ。チップの選択面は accent-dim（外観のテーマチップと同じ書式）。絞り込みの結果 0 件なら専用文言（`mcp_filtered_empty`）を出す ＝ 1 件も無い時の `mcp_empty`（登録のしかたを案内する文）と混ぜない
- **なぜ深さを付けたか**（2026-09-13 ユーザー判断）: MCP サーバは**上限の無い一覧**（`~/.codex/config.toml` / `~/.claude.json` / `~/.cursor/mcp.json` に足したものが全部並ぶ）で、1 枚スクロールだと外観以下が画面外へ押し下げられる。「MCP 専用の別画面へ遷移」ではなく**ページ化**を選んだのは、伸びるのは MCP だけではない（エージェント・リモート・この先の Fleet 設定）ため — 器を先に作れば、増える設定はナビに 1 行足すだけで済む。遷移型は「戻る」の状態を都度決める必要があり、方向感覚（§2）をいったん捨てる操作になる

## 13. Chat モード（M16）

**新しい部品は一覧だけ**で、会話は Agent パネル（§6）、成果物は既存のエディタ領域（§5）をそのまま使う。

| 中央 | Agent パネル（スレッドのタブ行は出さない）。右が閉じている時だけ列幅を 860px に絞る。上に**成果物の帯**（`▣ pomodoro.html` のチップ。開いている物だけスレッド色の下線）— ツールカードの `▣ プレビュー` は再起動で消えるので、成果物へ戻る道はここに常設。空のチャットは案内 4 行 |

| 成果物の出し方 | エージェントのターンが終わった時に、そのターンで書かれた HTML / Markdown をプレビュー表示で開く（**入力欄のフォーカスは奪わない**）。開いているタブの読み直しもターンにつき 1 回 |

## 14. 変更レビュー（Review）

worktree の変更を 1 画面で読む面。エディタのタブ（パレット「Git: 変更をレビュー」・ソース管理パネルの「⇄ 変更をレビュー」）と、
Fleet の Task カードの「変更」タブが **session ごとに同じ 1 枚**を載せる（Editor と Fleet は同時に描かないので、開いた畳み・見た印が揃う）。
エディタのコア（`editor_view`）は拡張しない。行の間にブロックを差し込む口も任意色の行背景も無いので、可変高の仮想リスト
（`crates/review_view`）に「ファイル見出し / 行 / 畳み / お知らせ」を並べる独立したビューにした（依存方向 = コアは機能を知らない）。

| 領域 | 仕様 |
|---|---|
| ツールバー（高さ 34・bg0・下罫線） | `☰`（ツリーの表示切替）/ `比較` + 基準チップ（押すとメニュー）/ `空白を無視`（`git diff -w`・ON は accent-dim の面）/ 右寄せ `N ファイル +A −D`（数字は ok / err）/ `↻`（読み直し）。作業ツリーが変わると `↻ 新しい変更があります`（枠 1px）に変わる — **自動では読み直さない**（読んでいる行を動かさない） |
| 基準メニュー（幅 380・最大高 380・bg2・影） | `Task の base`（Fleet の Task だけ・**既定**）/ `HEAD — 未コミットの変更だけ`（Task でなければ既定）/ ブランチ（HEAD との**分岐点**から＝PR と同じ見え方）/ コミット（直近 30 件・要約 + 短い SHA）。選択中は accent-dim の面。外側クリック / Esc で閉じる |
| ファイルツリー（左・幅 220・bg0・右罫線） | ディレクトリが先・子が 1 つのディレクトリは `a/b` に詰める・▾/▸ で畳む。行 = 状態の記号（A / M / D / R / U。色はソース管理と同じ ok / warn / err）+ 名前 + `+N −M`（fg2）。押すとその見出しへスクロール。いま見ているファイル（押した行 / スクロール位置の先頭）は bg3 + **左バー 2px プロジェクト色**（§1.3 のツリー選択）。見たファイルは名前 fg2 + `✓` |
| ファイル見出し（高さ 30・bg0・上下罫線） | `▾`/`▸`（畳む）+ 記号 + `dir/`（fg2）+ **名前** + 改名は `← 旧パス` + `+N −M` + （見た後で変わったファイルだけ `見た後に変更あり`・warn 10.5px）+ `☐ 見た`（押すと見た印を付けて畳む・もう一度で外して開く）+ `開く ↗`（削除以外・最初の追加行でエディタへ。Fleet では Editor に出て開く） |
| 行（最小高 20・Guguru Sans Code 12.5px・長い行は折り返す） | 旧行番号 / 新行番号（各 42px・右寄せ・fg2）+ 記号列 16px（`+` = ok / `−` = err）+ 本文。構文色は旧・新の**全文**をハイライトして行へ割り当てる（エディタと同じ syn-* 写像）。**追加行 = ok 12% の面・削除行 = err 12% の面**・文脈行は面なし。末尾に改行の無い行は `⏎̸ 末尾に改行なし`（fg2・10.5px） |
| 畳み（高さ 24・bg0） | `⋯ N 行` + 直後の hunk の見出し（git が拾った関数名・等幅 fg2）。押すと前後 20 行ずつ開く（先頭 = hunk 側の下から / 末尾 = 上から / 間 = 残り 40 行以下なら全部）。全文を読めないファイルは押せない |
| お知らせ行（高さ 28・fg2） | バイナリ / 大きすぎる（1 ファイル 5,000 行・全体 6 万行・**1 ファイルの差分 512KB・全体 16MB・中身が 4MB 超**・追跡外は 1MB か 1,000 件を超えた分と、全体の行・バイトの予算を超えた分・R02）/ 権限の変更だけ / 中身の変更なし。中身は出さず「開く」だけ |

- 中身は `git diff <基準>`（staged と unstaged をまとめて）+ 追跡外のファイル（全行を追加として）。改名は `-M`
- git・全文の読み込み・ハイライトは背景。先に差分を出し、色はファイル 8 件ずつ届いた分から付く。全文はレビュー全体で 24MB まで（超えた分のファイルは色無し・畳みは開けない・R02）。行の並べ直しは 120ms に 1 回へまとめる
- 読み直しても、開いた畳み・見た印・スクロール位置（同じ行）は保つ。ただし**見た印は「見た時の比較の基準 + そのファイルの差分の指紋」に結び付く**（R01）: 同じ基準で差分が変わっていたら印を外し、畳みを開いて見出しに `見た後に変更あり`（ツリーは `↻ +N −M`・warn）。基準を切り替えただけなら印は残る（戻せば復活）

### 14.1 行コメント（注記）と注記トレイ

diff の行に Markdown のコメントを付け、**まとめて 1 通**でエージェントへ送る。送り先の一覧と送信は Workspace が持つ
（ビューは AI を知らない）。注記は storage の `review_notes` に残る（再起動しても消えない）。

| 領域 | 仕様 |
|---|---|
| 行の選択 | 行を押すと選ぶ・⇧クリック / ドラッグで同じファイルの範囲。**選択 = bg3 70% の面 + 左バー 2px プロジェクト色**（§1.3 の選択の左バー。追加 / 削除の面は塗り潰さない）。↑↓ で動かす・Esc で外す |
| ＋（行の左端・16px・bg2・枠 1px） | 行にホバーすると出る（group hover）。押すとその行（選んでいる範囲の中なら範囲）に注記の入力欄を開く。選んで `c` でも同じ |
| 付く側 | 追加行・文脈行は**新しい側**、削除行は**古い側**の行番号。範囲に追加行があれば新しい側（抜粋には削除行も入る） |
| 入力欄（行の下・bg2 のカード） | 見出し `注記 path:行` + 入力（`EditorView` の平坦モード・高さ 72・bg1）+ `⌘⏎ で保存 · Esc で取り消し` + 取り消し / 保存。空なら何も残さない |
| 注記のカード（行の下・bg2・角 7） | `未送信 / 送信済み / 解決`（fg2・**状態に色相は使わない**）+ `path:行`（等幅 fg2）+ 編集 / 解決（解決済みは「未解決に戻す」）/ 削除 + 本文。解決は 60% の不透明度。直すと未送信に戻る。**置く前に、付けた時の抜粋と今の行の中身を突き合わせる**（R01）: 合えばそのまま / 同じ中身の並びが 1 か所だけあればそこへ移して保存し直す（改名は新しい名前へ）/ どちらでもなければ**位置が変わった注記** = 行には付けず、ファイル見出しの直後に `位置が変わった注記 — 付けた時の場所 …`（warn 10.5px）+ 元の抜粋（最大 6 行・等幅 fg2・bg1）。まだ読めていない行は確かめない（全文が届いたら確かめ直す） |
| トレイ（下端・高さ 34・bg0・上罫線） | 注記が 1 件以上ある時だけ。`▴ 注記 N 件（未送信 M）`（押すと一覧 = 最大高 200・行を押すとその注記へ飛ぶ・編集 / 解決 / 削除）+ `未解決だけ再送`（送信済みがある時）+ `送る ▾`（未送信がある時だけ押せる） |
| 送り先メニュー（トレイの上・幅 340・bg2・影） | `送り先（N 件を 1 通にまとめて）` + スレッド（● スレッド色 + 名前 + `エージェント · 状態`）。**既定**（Fleet = Task カードの操作先 / Editor = アクティブなスレッド）を先頭に accent-dim の面と `既定`。末尾に `＋ 新しいスレッドで送る`。宛先はスレッドの**永続 id** で持ち、送る直前に引き直す（R07）。閉じられていたら送らず、注記は未送信のままメニューを開き直す |
| 保存の失敗（トレイの右） | 注記の書き込みはビューごとに 1 本の列で積んだ順に流す（R03）。失敗した書き込みは `⚠ 保存できていない変更 N 件`（err 11.5px）+ `再試行` で書き直せる（本文はメモリに残る・消した注記は書き戻さない） |
| 送る | 1 通のプロンプト（`レビューコメント（N 件）— 比較: <短い SHA>..作業ツリー` + 各注記の `n. path:行`（位置が変わった注記は `（付けた時の場所・今の差分では見つからない）` を添える）+ 抜粋のコードフェンス（削除行を含めば `diff`）+ 本文）を**人間の発話として**送る。表示中のタブを奪わず、スレッドが実行中なら送信待ちに積む（ターン完了で裏のタブでも流れる）。届いたら `送信済み` + トースト `注記 N 件を ●スレッド へ送りました` |
