## ブランドロゴ（`brand-*.svg`）

AI エージェント識別用のブランドマーク（`brand-claude` / `brand-copilot` /
`brand-qwen` / `brand-opencode` / `brand-kimi`）は **Simple Icons**（https://simpleicons.org）由来。
Simple Icons の SVG は **CC0 1.0（パブリックドメイン）**。単色マスクとして描くため `fill` は
`currentColor` に正規化済み。

各ロゴが表す商標は各社（Anthropic / Google / GitHub / Alibaba / SST / Moonshot AI 等）に帰属し、
ここでは「どのエージェントに接続しているか」を示す**識別目的（nominative use）**でのみ使用する。
OpenAI/Codex のマークは Simple Icons に無いため頭文字モノグラムで代替。

## ファイルタイプの言語ロゴ（`file-*.svg`）

エクスプローラ/ファインダで拡張子を見分けるための言語・ツールロゴ（`file-rust` / `file-javascript` /
`file-typescript` / `file-tsx` / `file-python` / `file-go` / `file-json` / `file-yaml` / `file-toml` /
`file-html` / `file-css` / `file-markdown` / `file-shell` / `file-c` / `file-cpp` / `file-git` /
`file-docker`）も **Simple Icons**（CC0 1.0）由来。`fill` は単色マスク用に `currentColor` へ正規化済み。
各言語・ツールの商標は各権利者に帰属し、ファイル種別の**識別目的（nominative use）**でのみ使う
（Linguist / VSCode のファイルアイコンと同じ用法）。色は付けず `file_type_color` で薄く着色する。
