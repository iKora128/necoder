ORIENT BY COLOR

どこにいても、色でわかる。

プロジェクトごとに、色がひとつ。レールも、タブも、キャレットも、AI の返事も、その色をまとう。 いくつ並行しても、いまどこにいるかは目の端でわかる。飾りのための色は、ひとつもない。

触って確かめる

色を選ぶと、レールのアイコンもタブの上線もキャレットも選択バーも、一斉にその色になる。

AGENT-NATIVE (ACP)

AI スレッドは、色付きタブだ。

自前の AI は載せない。Claude Code が ACP（Agent Client Protocol）でそのまま動くから、 いまのサブスクリプションだけでいい。追加の API キーは不要。 スレッドごとに色が付き、どのスレッドがどこで働いているか、迷わない。

混戦しないための装備

  • 宛先チップ — 送信欄に「● スレッド名 + プロジェクト ⎇ ブランチ」を常時表示。誤爆しない
  • トークンメーター常時表示 — スレッド色のバーと 41.5k/1000k。status bar には全スレッド合計 Σ も
  • ⏺ トランスクリプト — ツール実行を一行ずつ。VSCode の Claude Code 拡張の読み味
  • 完了トースト — 「● worktree 並行レビュー ー 完了 44s」。よそのプロジェクトの完了も見逃さない
  • Enter の挙動は設定で選ぶ — 既定は Enter=改行 / 送信=⌘⏎（日本語変換の確定で誤送信しない）。Enter 送信に慣れているなら、トグル 1 つで切り替えられる

Todo ボードは、エージェントが消す。

真実はプロジェクト直下の .shirushi/todos.md という 1 枚の Markdown。 UI のチェックも、AI の完了報告も、同じファイルの [ ] → [x] 書き換えに落ちる。 人が書いても、エージェントが書いても、板は追従する。

  • ✨ 今日の計画 — ボードから直接 AI に段取りを組ませる
  • ファイルが真実 — git で差分も履歴も残る。ロックインなし

MULTI-AGENT FLEET

並走が増えたら、編隊で指揮する。

2 体、4 体、8 体 — エージェントが増えても迷わない。タイトルバーの Multi Agent で全画面が編隊モードになる。 色で「誰か」、形で「何をしているか」、系譜グラフで全体の流れが、目の端でわかる。

実機キャプチャ 左=エージェント一覧（色=識別）· 中央=系譜グラフ + N 分割グリッド

系譜グラフは、4 つの視点で。

最重要ビジュアル。すべてネイティブ描画（webview なし）。base から分岐し、完了は main へ統合。 レーンとノードは識別色、先端は状態の形。切り替えて、畳める。

扇形 — base から放射状に分岐。並走の"広がり"が一目でわかる既定表示。

縦ツリー — 上から下への枝分かれ。分岐の"深さ"を辿るのに向く。

カード — 曲線の先が読めるカードに。名前・状態・トークンまで一望。

ハブ — 中央=リポジトリ、スポークが各エージェントへ。歯車のように全体を俯瞰。

STATE = SHAPE

状態は、色じゃなく形で。

作業中 承認待ち 完了 待機

状態に色相は使わない。● 作業 / ◐ 承認待ち / ✓ 完了 / ○ 待機 を形と動きで示す。 色は最後まで「誰か」の識別色のまま、状態と衝突しない。承認待ちは半円で、速く脈打つ。

WORKTREE = SPACE

＋Agent は、作業空間ごと。

＋ から Agent＋⎇worktree を選べば、その場に隔離ブランチ agent/N を切り、独立した作業空間（space）ごとエージェントを起動。 worktree の生成はアプリが所有する。左レールに並び、切り替えれば端末・エディタごと追従する。

どのセルも、プレースホルダじゃない。

エージェントセルは本物のトランスクリプト、ターミナルセルは本物の端末。編隊は別ビューではなく、同じ編集コアの上に立つ。

  • ⤢ 最大化 — 1 体に集中。系譜グラフが退き、他はサムネイル列へ畳まれる
  • 色 = 識別を継承 — セルの上線・ドット・グラフのレーンまで同じスレッド色
  • 最大 8 セル — ＋ で自動レイアウト（4→2×2 / 6→3列 / 8→4列）

CROSS-PROJECT × WORKTREE

⌘O いま、どこで、何が動いてる？

ブランチごとに、窓がひとつ。⌘O を押せば、全プロジェクトと worktree、 そこで走っているスレッドまで一覧に出る。⌘1..9 で瞬間切替。 エージェントはブランチごとに並行で走らせる。

⌘O プロジェクト / worktree 切替

A REAL EDITOR

エディタとしても、ちゃんと速い。

AI が主役でも、手で書く時間は消えない。ropey ベースの編集コア、rust-analyzer の言語知能、 Git、ターミナル、Remote SSH — 毎日使う道具として作っている。

すべてのコマンド ⌘⇧P

全操作に、キーバインド表示つきで届く。ファイルは ⌘P — 50,000 件でも 10ms で絞り込む。

⌘⇧P コマンドパレット

検索 ⌘F

打つたびに絞れて、全マッチが灯る。置換は 1 回の undo で戻せる。プロジェクト全体の検索も ⌘⇧F で。

⌘F バッファ内検索

差分は、タブで開いて読む。

変更したファイルの diff は、HEAD と並べてタブで開ける。追加と削除がひと目でわかる。ツリーやガターにも、どこが変わったかの印が灯る。

THEMES

きせかえは、JSON 1 枚。

テーマは JSON 1 枚。18 色を書き換えれば自分の配色になるし、2 色だけ変えても成立する。 テーマを替えても、プロジェクト色の方向感覚はそのまま。切替は ⌘K ⌘T。
