WebView の evict って 15 分が妥当？短くすると何が困る？

メモリを優先するなら 5 分、作業中の往復が多いなら 15 分のままを勧めます。

設計メモ（DECISIONS 2026-09-18 / CHAT.md）

  1. モードは 3 つ: Editor / Fleet / Chat。Chat はプロジェクトに属さないので、ピルに ⎇ branch が出ず、額縁は無彩色。「色のある窓 = プロジェクト、色のない窓 = Chat」が方向感覚になる。
  2. レールは残す。プロジェクトを押せばその Editor へ戻る。エクスプローラ・検索・Git はプロジェクトの機能なので Chat では薄くする。他プロジェクトのビーコンは Chat にいても見える。
  3. チャット = thread（別の型を作らない）。行頭 ● はスレッド色、選択は左バー。状態は形と動き: 塗り = 起動中 / 点滅 = 応答中 / 輪郭だけ = エージェント未起動。一覧に並んでいるだけではプロセスを起こさない（idle メモリ予算）。
  4. transcript は agent_panel のまま（⏺/⎿・✳）。相談にはテキストだけで答え、ファイルを作らない。成果物を頼まれた時だけ artifacts/ に 1 ファイル Write し、修正は同じファイルの Edit。▣ プレビューチップはツール呼び出しの構造化されたパス + 実在確認 + 拡張子で出す（文言は解析しない）。
  5. 右は既存のエディタ領域。artifact 専用ペインは作らない。タブ下線はそれを書いたスレッドの色。artifact が無い会話では閉じていて、transcript が中央に広がる（状態「相談だけ」）。
  6. プレビュー ⇄ ソースは既存の ⌘⇧V。ソースでは自分で編集でき、エージェントが触った行は gutter がスレッド色。再読込はターン終了時に 1 回（途中で読み直すとタイマーなどのページ状態が消える）。隔離表示 = 配信は artifacts/ のみ・外部通信なし・外部リンクは既定ブラウザ（ROADMAP C3）。
  7. 宛先チップとトークンは常時表示（必須要件）。宛先は「スレッド名 ／ Chat」。権限モードのピルは出さず、書込 フォルダ + 添付を固定で示す。最初は Claude のみ。
  8. 保存場所は 書類/necoder/<日付 最初の文>/artifacts/（statusbar に表示）。最初の送信時に作り、空のまま終われば消す。名前は作成後に変えない。ファイルを渡す = 触ってよいと伝える（状態「ファイルを渡す」）: 元の場所のまま扱い、読み取りは自動、書き込みは初回だけ確認。それ以外への書き込みは拒否。
