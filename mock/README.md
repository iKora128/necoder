# ビジュアルモック

`index.html` をブラウザで開くだけ（依存ゼロ・オフライン可）。
GPUI で実装する前に **ここで見た目と操作の骨格を確定させる** ための道具。

```sh
open mock/index.html
```

## 何を表現しているか（ビジョン → UI の翻訳）

| ビジョン | モック上の表現 |
|---|---|
| **プロジェクト横断の方向感覚**（最重要モチベ） | 最左の**プロジェクトレール**。プロジェクトごとの色付きアイコンで、クリックすると**窓全体の色（額縁・タブ・ツリー選択・statusbar）が切り替わる**。実行中エージェントのドットも各プロジェクトの下に出る＝「どのPJで何が走っているか」が常時見える |
| **ブランチ横断** | titlebar の `⎇ main ▾` クリックで**ブランチ / worktree メニュー**。worktree で並行に開いているブランチ、そこで走るエージェントのドット、「ブランチを worktree で開く（並行作業）」導線 |
| 直感的な移動 | **⌘O スイッチャー**: プロジェクト（⌘1..4 で即ジャンプ）→ その下にブランチ/worktree がぶら下がる2階層。エージェント実行中の場所が光る |
| **スレッドの方向感覚**（Zed最大の不満） | Agent パネルは**スレッド＝色付きタブ**。titlebar のビーコンと statusbar のドットにも同じ色（実行中は点滅）。さらに**タブを切り替えるとスレッド色が入力枠・送信ボタン・宛先チップまで流れる**ので、「いまどのスレッドに書いているか」を取り違えない |
| 混戦対策の宛先チップ | 入力欄の上に「● スレッド名 ／ プロジェクト ⎇ ブランチ」を常時表示。送信先が一目で分かる |
| チャットの見た目 | **VSCode の Claude Code 拡張を踏襲**: ⏺ ステップ + ⎿ 結果行のトランスクリプト、✳ Thinking…、Update Todos 表示。⏺ は Claude テラコッタ（#d97757）、識別色はスレッド色が担当 |
| トークン不可視の痛点 | スレッドメタ行に常時トークンメーター |
| thinking 常時展開・IME対策 | thinking ブロック展開表示、「Enter=改行 / ⌘Enter=送信」明記 |
| **UI拡張は一級市民** | 左下「TODOコメント（拡張UIデモ）」= 拡張が描いたパネルがネイティブUIと同じ見た目で同居する、というデモ。statusbar の「拡張 tokei」も同様 |
| Finder的エクスプローラ | **左ドック下部のビュー切替**（本体UI・Finderツールバー相当）で **ツリー / カラム / アイコン** を切替。カラム=Miller、アイコン=グリッド、いずれも下部パスバー付き。mockbar からも切替可 |
| ファイルブラウザ挙動 | アイコンビューに ‹ › ↑ の階層ナビ。**右クリックで実際にメニューが出る**（ファイル=開く・分割して開く / フォルダ=**新しいウィンドウでプロジェクトとして開く** / パスコピー / リネーム / ゴミ箱）。ツリー/カラムの行でも右クリック可 |
| プロジェクトのカスタムアイコン | レール3つ目（🧬）＝ `.shirushi/settings.json`（`.vscode`/`.claude` 相当のプロジェクトローカル設定）で画像/絵文字を指定する想定のデモ。1つ目は 印 モノグラム |
| 上位階層へ辿る | プロジェクトパネルのヘッダが **Work › experience › shirushi** のブレッドクラム。親フォルダをクリックでどんどん上へ。任意フォルダは右クリック→「新しいウィンドウでプロジェクトとして開く」と対になる |
| 色の使用原則（v0.2） | アクセントは**識別が要る場所だけ**（レール・ピル左縁・タブ下線・キャレット・ツリー選択の左バー）。titlebar/statusbar のグラデ額縁・選択面の色塗り・フォルダアイコンのアクセント連動は**廃止**（フォルダは固定ブルー） |

## 上のコントロールバーで決めること

1. **テーマ**: Dark / Light（配色トークンは CSS 変数に集約 → GPUI theme 構造体の雛形）
2. **プロジェクト色**: スウォッチ or レールのクリックで「窓の空気がどれくらい変わるべきか」の濃度確認
3. **密度**: Compact（Zed寄り）/ Cozy
4. **エクスプローラ**: ツリー / カラム / アイコン — 既定をどれにするか（切替UI自体は左下に常設で決定済み）
5. **レイアウト**: ドック開閉、⌘⇧P パレット、⌘O スイッチャー

## まだ決めていない（次のイテレーション）

- フォント、ファイルアイコンの有無、タブの形状
- レールの位置（左固定か、titlebar 内に横並びか）と表示情報量（アイコンのみ / 名前つき）
- カラム表示を「サイドバーの表示モード」に留めるか、**ディレクトリを一級のビュー（タブ）として編集領域に開く**（oil.nvim / dired 方向）まで踏み込むか
- スレッド色・プロジェクト色の自動割当ルール（固定パレット巡回 or 手動）

## 推奨（作者の提案）

**Dark + Compact + レール常設**。プロジェクト色は「額縁」（titlebar/statusbar の淡いグラデ + レール）に留め、
彩度の高い面は使わない — 色は「識別」のためだけに、最小の面積で。
