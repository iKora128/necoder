2026-10-02 · 中身はエージェントが実際に広告している設定（claude-agent-acp 0.81.2・codex-acp 1.13.1 の configOptions）。今は boolean を捨てているので Fast が選べない（acp_client.rs の map_config_option）。どちらの形でも boolean は出せる。
追加で選ぶこと（2026-10-02）: 思考量のゲージ — 下の「0.」に G-1〜G-4 を並べました（「G-2」のように一言で）。
決定（2026-10-02・本人）: 案 C + C-1 — チップ 1 つ → カード 1 枚、権限モードはカードの外のピル。実装は crates/agent_panel/src/config_card.rs（UI-SPEC §6）。以下は決める時に並べた比較のまま残す。

5. キー（衝突を確かめた結果）

キーどこで動き衝突
⌘/（Windows / Linux は Ctrl+/）composer の中カードを開く / 閉じるエディタの「コメントの切り替え」と同じキー（Editor 文脈）。composer にはファイルが無くコメントの記号が決まらないので今は何も起きない。割り当ては AgentPanel > Editor の文脈にだけ置くので、コードのエディタの ⌘/ は変わらない。OS の既定のショートカットとも重ならない
/model—使わないClaude Code 自身のコマンド（/model opus を送るとモデルが変わり、アダプタがピッカーへ映し返す）。necoder が取るとエージェントへ届かなくなる。/ 補完はエージェントの物のまま
チップを押す—カードを開く / 閉じる—
↑ ↓カードモデルの一覧へ（隣のモデルに印）。一覧では印を動かし ⏎ で決めてカードへ戻るカードがキーを持つ間だけ（composer の行の移動はカードを閉じれば元どおり）
← →カード思考量を 1 段ずつ（その場で送る）同上
Tab / ⇧Tabカードエージェントを次 / 前へ。会話を始める前だけ（後は何もしない・行に「この会話では固定」）同上
escカード / 一覧一覧ならカードへ戻る・カードなら閉じて composer へ（ターンは止めない）今の「esc でターンを止める」より先に取る（開いている間だけ）
押すboolean の行on / off（その場で送る）キーは付けない

6. 実装の決まり（どちらの形でも）

  • boolean を受け取る: map_config_option が boolean も写す。送る値は select = value_id・boolean = true/false（session/set_config_option の type: "boolean"）。カテゴリ mode の設定は権限モード（session/set_mode）と二重なので出さない。
  • sticky: 今の model / effort / mode に加えて、ほかの設定もエージェントごとに覚える（agent_config_defaults.claude.fast = "true"・キーは ACP の config_id）。次のスレッドはセッションを開いた直後・最初の送信より前に合わせる。エージェントが値を戻した時（使えない等）は言い返さずに従う。
  • 捏造しない: 広告が届く前は開けない。在庫（同じエージェントが一度広告した物）があればそれで開ける。広告に無い値は送らない。
  • 色: カードは bg2・枠 1px・角 10・影（最前面に描く）。選択と印は bg3、つまみは fg0、トラックは bg3 / fg2。稲妻は絵文字ではなく線の絵 （色相なし）。
